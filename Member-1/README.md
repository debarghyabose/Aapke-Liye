# 🤖 Member 1: AI/ML (Speech + Claim AI)

**Name:** _your name_ · **GitHub:** _@handle_

## Your job
Make the app understand people. Turn what a victim says, in their own language, into a structured relief claim.

## Phase 1: Core demo (build first)
- [ ] **Speech to text** in 6 languages (English + India's top 5) using Bhashini or Whisper
- [ ] **Claim AI:** an LLM turns the speech into claim fields: name, location, type of loss, amounts
- [ ] **Missing fields:** detect what's still needed and write a follow-up question
- [ ] Test with sample recordings in every language

## Phase 2: Roadmap features (after the demo works)
| Feature | What to do |
|---|---|
| Before/after damage comparison | AI compares the normal-time "baseline" photo with the damage photo and scores the damage |
| Replacement applications | The LLM drafts reissue requests for lost Aadhaar, ration card and land records |
| Insurance claims | The LLM writes home, vehicle and crop insurance claims from the same claim data |
| Auto-escalation letters | The LLM drafts follow-up letters, grievances and RTI applications for stuck claims, using Member 5's templates |
