# 🔊 Prerecorded prompts — Owner: 🎨 M1

Used when there is no network (steps 3b and 5). One folder per language: `hi/`, `bn/`, `mr/`, `ta/`, `te/`, `en/`.

Format: Opus `.ogg`, mono, 16 kbps, to keep the download small.
